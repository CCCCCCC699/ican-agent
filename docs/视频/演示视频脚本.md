# 申城智行 演示视频脚本（≤5分钟）

## 总体结构

| 段落 | 时长 | 内容 |
|---|---|---|
| 1. 痛点引入 | 0:00-0:30 | 出行痛点 → 项目一句话定位 |
| 2. 架构与Agent机制 | 0:30-1:30 | 架构图讲解 + 三Agent协作机制 + "AI管语义、算法管计算" |
| 3. 实操演示（5场景） | 1:30-4:00 | 逐场景操作，**镜头重点给Agent运行轨迹面板** |
| 4. 创新点与价值 | 4:00-4:40 | 创新点总结 + 商业模式 |
| 5. 结尾 | 4:40-5:00 | 团队 + 结束语 |

## 分镜与台词

### 段落1：痛点引入（30s）
**画面**：录屏首页"申城智行"标题，穿插地铁实景素材（可无）

**台词**：
"上海地铁每天运送超过一千万人次。但你有没有遇到过这样的情况：想去五角场，路上要先去徐家汇办点事；高峰期想绕开人民广场——打开出行App，却发现它根本听不懂你的需求。
我们带来了'申城智行'——一个用大模型和知识图谱打造的轨道交通出行智能体。你开口问，它给你可解释、可溯源的答案。"

### 段落2：架构与Agent机制（60s）
**画面**：架构图（PPT/截图），依次高亮三个Agent

**台词**：
"系统的核心是三个智能体协作：意图路由Agent理解你的需求——比如提取起点、途经点、避让站；Text2Cypher Agent把问题翻译成知识图谱的只读查询；答案生成Agent基于图谱证据组织回答。
最关键的设计是：AI管语义，算法管计算。路线怎么走，由知识图谱上的确定性图算法算出来——大模型永远编不出不存在的线路。每条回答都能在图中找到依据。"

### 段落3：实操演示五场景（150s，每场景30s）
**画面**：浏览器全屏操作，输入问题→等待→**镜头切到右侧"Agent运行轨迹"面板**→展示回答

1. **基础路线规划**："从虹桥火车站到陆家嘴怎么走最快？"
   **旁白**："系统识别为路线规划意图，图算法给出2号线直达方案，36分钟，无需换乘。"
2. **途经点约束**："从莘庄去五角场，途中经过徐家汇"
   **旁白**："复合约束——途经徐家汇。系统将行程分段规划，逐段给出线路与耗时。"
3. **信息查询**："2号线经过哪些换乘站？"
   **旁白**："信息查询类问题由Text2Cypher智能体在后台翻译成图查询、经只读安全校验后执行——答案完全来自图谱数据，下方的证据芯片可逐条溯源。"
4. **换乘查询**："人民广场可以换乘哪几条线？"
   **旁白**："图谱证据实时展示，每条结论可溯源。"
5. **避让约束**："从上海南站到五角场，避开人民广场"
   **旁白**："避让约束下，系统重新计算绕行路线，同时图谱可视化同步展示路网结构。"

### 段落4：创新点与价值（40s）
**画面**：创新点要点列表逐条出现

**台词**：
"总结一下：多智能体协作、可控生成杜绝幻觉、Text2Cypher安全校验、复合约束规划——以及云API与本地模型双模式部署，让它既能服务公众，也能进入对数据安全有严格要求的地铁运营方。C端免费、B端授权的商业模式已经清晰。"

### 段落5：结尾（20s）
**台词**："申城智行——让每一次出行，都答得上来。感谢观看。"

## 制作要点

- 录屏1920×1080，浏览器缩放至125%保证文字清晰
- **每一场景回答时，鼠标指向Agent运行轨迹面板停留2秒**（大赛要求突出智能体运行过程）
- 旁白用AI配音（如剪映/魔音工坊）或真人配音，语速平稳
- 5个场景可先预演2遍，确保无报错、无卡顿（可提前录好备用片段）
- 导出MP4、H.264、≤200MB；成片时长控制在4:50以内
